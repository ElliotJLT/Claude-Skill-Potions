# clone the potions
git clone https://github.com/ElliotJLT/Claude-Skill-Potions.git ~/.claude/skills

How it works

Three layers. No bloat.

1

Metadata

Name + description acts as the trigger. ~100 tokens, always loaded.

2

Instructions

Step-by-step workflow. Only loaded when the skill triggers.

3

Resources

Scripts execute and return output. They don't bloat context with code.

Potions

Each one does one thing well.

planning

battle-plan

Complete planning ritual before significant tasks. No coding until the plan is approved.

 planning

pre-mortem

Imagines failure scenarios, assesses risks, reorders implementation to address high-risk items first.

 context

dont-be-greedy

Prevents context overflow by estimating file sizes and chunking large data before loading.

 debugging

rubber-duck

 quality

 discipline

 context

breadcrumbs

 meta

skill-forge

Auto-generates new skills from real discoveries. The library grows from real work, not theory.

 debugging

zero-in
