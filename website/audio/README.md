# Audio Files

Add the following royalty-free audio files:

## Required Files

1. **ambient-cave.mp3** - Ambient cave/dungeon background loop
   - Suggested: [Freesound - Cave Ambience](https://freesound.org/search/?q=cave+ambience)
   - Keep it subtle, ~30-60 seconds loop

2. **bubble.mp3** - Potion bubbling sound loop
   - Suggested: [Freesound - Bubbling](https://freesound.org/search/?q=bubbling+potion)
   - Soft, non-distracting, ~10-20 seconds loop

3. **pop.mp3** - Cork pop for selection
   - Suggested: [Freesound - Cork Pop](https://freesound.org/search/?q=cork+pop)
   - Short, satisfying click (~0.5 seconds)

4. **clink.mp3** - Glass clink for filter/deselect
   - Suggested: [Freesound - Glass Clink](https://freesound.org/search/?q=glass+clink)
   - Subtle, short (~0.3 seconds)
