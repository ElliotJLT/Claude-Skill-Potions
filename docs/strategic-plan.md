## What NOT To Do

### Don't build a marketplace
- Marketplaces are a platform play requiring critical mass, capital, and years
- SkillsMP already indexes 66k+ skills for free
- Anthropic or the community will likely build the official one
- You'd be competing with infrastructure, not building on your strength
- Your instinct that this "felt risky" was correct

### Don't sell individual skills
- Skills are markdown files. They get copied and shared instantly
- The SKILL.md format is open standard. No DRM, no lock-in
- The floor price for individual skills will rapidly approach $0
- Fighting this is fighting gravity

### Don't wait for the "right" product idea
- The market is moving. Every week you wait, 10 more people discover this space
- Shipping imperfect things now beats shipping perfect things later

## The Strategy: Authority-First Monetization

**Core thesis:** You don't sell skills. You sell the ABILITY to create, combine, and deploy skills effectively. Skills are the free sample. Your expertise is the product.

### Phase 1: Establish Authority (Weeks 1-4)
**Goal: Become the recognized name in Claude Skills**

**1. Content machine (pick 2 of 3):**
- **Twitter/X threads**: Show real workflows. "Here's how I used 3 skills to debug a production issue in 4 minutes." Daily. This is where the Claude community lives
- **YouTube shorts/videos**: Screen recordings of skills in action. "Watch battle-plan prevent me from wasting 2 hours." The visual proof is compelling
- **Newsletter**: Weekly "Potion of the Week" - one skill deep dive, one workflow recipe, one lesson from operating Claude daily

**2. Strategic open source:**
- Keep Skill Potions open and growing. This is your credibility, not your product
- Contribute to the Obsidian + Claude conversation. Comment on kepano's repo, Reddit threads, HN posts
- Create an "awesome-claude-skills" list or contribute to existing ones
- Target: 500+ GitHub stars (from current few → visible in the ecosystem)

**3. Position as "The Operator":**
- Your LinkedIn already says "hire elliot" - lean into this
- Frame yourself not as a tool builder but as someone who makes AI tools WORK in practice
- "I use Claude Code 8 hours a day. Here's what I've learned." This is rare and valuable

### Phase 2: Monetize the Authority (Weeks 4-12)
**Goal: First revenue from 2-3 channels**

**Option A - Premium Skill Bundles on Gumroad ($19-49)**
- NOT individual skills (those stay free)
- Curated "Elixir Packs" - complete workflows for specific use cases:
  - "The Obsidian Power User Pack" - all Obsidian skills + custom CLAUDE.md + setup guide + video walkthrough
  - "The Production Safety Pack" - battle-plan + pre-mortem + prove-it + you-sure + configuration for a real project
  - "The Solo Dev Toolkit" - breadcrumbs + debug-to-fix + safe-refactor + retrospective, configured for solo workflows
- Include video setup guides, custom configurations, real-world examples
- Price: $19-39 each. The value isn't the markdown - it's the curation + configuration + education
- Revenue target: $500-2k/month (20-100 sales/month is realistic with audience)

**Option B - Claude Code Implementation Consulting ($150-300/hr)**
- Target: dev teams adopting Claude Code who don't know where to start
- Offer: "I'll set up your team's Claude Code environment with custom skills in a day"
- Deliverable: Custom CLAUDE.md, project-specific skills, hook configuration, team onboarding
- Entry point: 2-hour "Claude Code Audit" ($300-600) where you review their setup and give recommendations
- Revenue target: 2-4 clients/month = $2,400-4,800/month (part-time alongside day job)

**Option C - Course/Workshop ($49-199)**
- "Build Your Own Claude Skills" - hands-on course
- Covers: SKILL.md format, testing skills, activation reliability, elixir patterns, hooks
- Platform: Gumroad, Podia, or self-hosted
- Sell into the audience you're building in Phase 1
- Revenue target: $1-3k/month after launch

### Phase 3: Scale What Works (Months 3-6)
**Goal: $5-10k/month from the channel that hit**

Pick the winner from Phase 2 and double down:
- If bundles win → create more packs, raise prices, add subscription tier
- If consulting wins → productize into packages, raise rates, bring on a second operator
- If courses win → create advanced course, add community tier, do live workshops

**New channel to explore: Sponsored content / DevRel partnerships**
